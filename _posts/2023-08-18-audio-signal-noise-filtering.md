## 一、实验目的
利用声音信号的特殊频带，通过加入噪声，设计滤波器对噪声进行处理，达到对声音信号分析与处理的目的。

## 二、实验要求
1. 利用计算机的录音机功能，采集一段小于一定时长的音频信号（语音信号采集及处理），存于文件。
2. 利用MATLAB的 `audioread` 函数，读取采集数据，提取其数据采集频率等参数。
3. 对该信号加入多种噪声，如随机噪声、有色噪声等，送至播放器播放。
4. 根据加噪信号的频谱特征，设计数字滤波器对该音频信号进行处理，并给出设计指标。
5. 将滤波后的语音信号送至播放器播放，分析滤波效果，并进一步优化滤波器设计方案。

## 三、技术方案
设计滤波器并滤波的主要步骤（窗函数法）：
1. 根据理想滤波器频率响应写出单位脉冲响应 hd(n)。
2. 将模拟频率对采样率归一化。
3. 计算过渡带宽度。
4. 根据阻带最小衰减选择窗函数。
5. 求窗长度 N。
6. 求截止频率 wc。
7. 计算滤波器系数向量 h(n)。
8. 绘制滤波器频率特性波特图，完成滤波。

本实验具体流程：
- 利用电脑录音功能录制一段语音（如“信号实习”），保存为 `录音.m4a`。
- 使用 `audioread` 读取音频数据，获取采样率 Fs，将双声道数据拆分为两列。
- 播放原始信号（使用 `sound` 函数，注意先 `clear sound` 防止多段录音混叠）。
- 绘制原始信号的时域波形和幅度谱。
- 生成一个高频正弦噪声（频率 12kHz，幅值 0.1），叠加到原始信号上，形成带噪信号。
- 播放加噪信号，绘制其时域和频谱图。
- 分析频谱，设计低通滤波器（汉宁窗），滤除高频噪声，保留语音主频。
- 设计指标：根据噪声频率与语音频带，取通带截止频率 wp=0.36π，阻带截止频率 ws=0.98π（归一化数字频率），采用汉宁窗，过渡带宽度 Bt = ws - wp，窗长 N 由公式 N ≈ 6.2π/Bt 计算并取奇数。
- 用 `filter` 函数对加噪信号进行滤波，播放滤波后信号，绘制时域和频谱图。
- 对比滤波前后的时域波形和频谱，主观评价滤噪效果。

## 四、实验程序
```matlab
clc;
clear;
close all;

% 读取音频文件
[Y, Fs] = audioread('F:\bin\win64\信号实习\录音.m4a');
Y1 = Y(:,1);   % 左声道
Y2 = Y(:,2);   % 右声道
N = length(Y);
ts = 1/Fs;

% 原始信号时域
subplot(3,2,1), plot(Y, 'c'), title('原声音信号');

% 原始信号频谱
y1 = fft(Y) * ts;
z1 = abs(y1);
if mod(N,2)==0
    k = -N/2:(N/2-1);
else
    k = -(N-1)/2:(N-1)/2;
end;
f1 = k*Fs/N;
subplot(3,2,2), plot(f1, fftshift(z1), 'y'), title('初始信号频谱');

% 生成高频噪声 (12kHz)
f = 1.2E4;
t = 0:ts:(N-1)*ts;
noise = 0.1 * sin(2*pi*f*t);
% 分别对两个声道加噪
X1 = Y1 + noise';
X2 = Y2 + noise';
X = [X1, X2];

subplot(3,2,3), plot(X, 'm'), title('加噪声后声音信号');

% 加噪信号频谱
y2 = fft(X) * ts;
z2 = abs(y2);
f2 = k*Fs/N;
subplot(3,2,4), plot(f2, fftshift(z2), 'g'), ylim([0,0.08]), title('加噪声后声音信号频谱');

% 设计低通滤波器（汉宁窗）
ws = 0.98*pi;   % 阻带截止频率
wp = 0.36*pi;   % 通带截止频率
Bt = ws - wp;
N0 = ceil(6.2*pi / Bt);      % 汉宁窗过渡带宽度近似
N1 = N0 + mod(N0+1, 2);      % 保证奇对称
wc = (wp + ws) / 2;           % 实际截止频率
hn = fir1(N1-1, wc/pi, 'low', hanning(N1));

% 滤波
y = filter(hn, 1, X);

subplot(3,2,5), plot(y, 'r'), title('滤波后声音信号');

% 滤波后频谱
y3 = fft(y) * ts;
z3 = abs(y3);
f3 = k*Fs/N;
subplot(3,2,6), plot(f3, fftshift(z3), 'b'), title('滤波后声音信号频谱');

% 试听（可用 sound 函数，注意先 clear sound）
% 原始：sound(Y, Fs);  pause(3);
% 加噪：sound(X, Fs);  pause(3);
% 滤波：sound(y, Fs);
```

## 五、实验结果

实验得到三组时域波形和相应的幅度谱（图1至图6）：

- **原始信号**：时域波形平滑，频谱能量集中在低频段（语音主频通常在 300Hz~3.4kHz 内）。
- **加噪信号**：波形出现明显高频抖动，频谱中在 12kHz 处出现新增谱峰，高频噪声干扰严重，播放时听到嘈杂的“滋滋”声。
- **滤波后信号**：时域波形恢复平滑，频谱中 12kHz 噪声被有效衰减，低频语音成分保留完整。播放滤波后声音，语音清晰度明显提升，噪声基本被消除。

通过与原始信号的对比，滤波后信号在时域和频域上均与原始信号高度吻合，说明所设计的低通滤波器（汉宁窗，阶数约 N≈65）能够有效滤除 12kHz 噪声，同时保留语音频带内的有用成分。

**设计指标总结**：
- 通带截止频率 fp = 0.36π（对应模拟频率约 4.5kHz，考虑到语音带宽）
- 阻带截止频率 fs = 0.98π（对应约 12.25kHz）
- 过渡带宽 ≈ 0.62π
- 窗函数：汉宁窗（阻带衰减约 44dB）
- 实际窗长 N ≈ 根据公式计算得到，满足过渡带要求

**优化建议**：若噪声频率更接近语音频带，可采用更高阶滤波器或改用凯泽窗，以更陡的过渡带换取更好的阻带衰减，同时注意保持线性相位特性。
