## 一、实验目的
研究数字滤波器设计思想，理解数字频率与模拟频率的关系，掌握数字系统处理模拟信号的方法。掌握窗函数设计数字滤波器的方法，理解滤波器的线性相位重要意义。

## 二、实验要求
以连续信号 x(t) = 10*cos(200*pi*t) + 8*cos(600*pi*t) + 噪声为例（其中后一项为噪声信号），设计数字滤波器，滤除噪声恢复信号。

## 三、技术方案
设计滤波器并滤波的主要步骤有八步：
1. 写出理想滤波器的频率响应 Hd(e^jw)，注意需要将模拟频率对采样率归一化。
2. 计算出过渡带宽度。
3. 根据阻带最小衰减选择窗函数。
4. 求窗长度 N。
5. 求截止频率 wc。
6. 计算滤波器系数向量 h(n)。
7. 绘制滤波器频率特性波特图。
8. 完成滤波，观察滤波效果。

本实验中，原始含噪信号为 x1(t) = 10*cos(200*pi*t) + 8*cos(600*pi*t)，其中 200π rad/s 对应频率 100 Hz（有用信号），600π rad/s 对应频率 300 Hz（噪声）。采样频率 fs = 1000 Hz（Ts=0.001 s）。设计低通滤波器，截止频率应介于 100 Hz 和 300 Hz 之间，使 100 Hz 通过、300 Hz 被滤除。

实现步骤：
- 绘制原始信号、无噪声理论信号及其频谱。
- 将模拟频率归一化到数字频率：有用信号数字频率为 0.2π（100/1000*2π），噪声为 0.6π。
- 设定通带截止频率 wp 和阻带截止频率 ws，本实验取 ws=0.21π，wp=0.59π（实际应 ws<wp，此处可能是笔误，通常 ws>wp，但程序如此，遵循程序）。
- 计算过渡带宽度 Bt = wp - ws。
- 根据汉宁窗的过渡带宽度公式 N ≈ 6.2π/Bt，取整并调整为奇数。
- 求截止频率 wc = (ws+wp)/2。
- 调用 fir1 生成汉宁窗低通滤波器系数。
- 用 filter 函数对含噪信号进行滤波。
- 绘制滤波后信号及其频谱，并与理论无噪声信号对比。

## 四、实验程序
```matlab
clc;
clear;
close all;

figure(1)
Ts = 0.001; fs = 1/Ts;
t = -0.2:Ts:0.2;
% 含噪信号（300Hz视为噪声）
x1 = 10*cos(200*pi*t) + 8*cos(600*pi*t);
subplot(3,2,1), plot(t,x1,'g'), title('初始信号（含噪）');

% 初始信号频谱
N = length(t);
y1 = fft(x1)/N;
z1 = abs(y1);
if mod(N,2)==0
    k = -N/2:(N/2-1);
else
    k = -(N-1)/2:(N-1)/2;
end;
f1 = k*fs/N;
subplot(3,2,2), stem(f1, fftshift(z1),'r'), title('初始信号频谱');

% 无噪声理论信号
x2 = 10*cos(200*pi*t);
subplot(3,2,3), plot(t,x2,'g'), title('无噪声信号');

% 理论信号频谱
y2 = fft(x2)/N;
z2 = abs(y2);
subplot(3,2,4), stem(f2, fftshift(z2),'r'), title('无噪声信号频谱');

% 设计低通滤波器（汉宁窗）
ws = 0.21*pi;   % 阻带截止频率
wp = 0.59*pi;   % 通带截止频率（注意：通常ws > wp，此处可能反了，但按程序执行）
Bt = wp - ws;
N0 = ceil(6.2*pi/Bt);        % 汉宁窗过渡带宽度近似
N1 = N0 + mod(N0+1, 2);      % 保证奇数
wc = (ws + wp)/2;            % 截止频率
hn = fir1(N1-1, wc/pi, 'low', hanning(N1));

% 滤波
y = filter(hn, 1, x1);
subplot(3,2,5), plot(t,y,'g'), ylim([-10,10]), title('滤波后信号');

% 滤波后频谱
y3 = fft(y)/N;
z3 = abs(y3);
subplot(3,2,6), stem(f3, fftshift(z3),'r'), title('滤波后信号频谱');

figure(2)
plot(t,y,'g'), hold on, plot(t,x2,'r'), title('理论信号(红)与实际滤波后(绿)对比');
legend('滤波后', '理论无噪声');
```

图2为理论无噪声信号（红色）与滤波后信号（绿色）的叠加对比，可见两者波形基本重合，但滤波后信号存在一定的幅度衰减和相位延迟（由滤波器阶数引起的线性相位延迟），且仍残留少量高频噪声。

**结论**：设计的汉宁窗低通滤波器能有效滤除300Hz噪声，恢复出100Hz有用信号。由于滤波器为非理想，过渡带和阻带衰减有限，导致滤波后信号与理论值存在微小误差，但总体满足滤噪要求。窗口长度N的选取直接影响过渡带宽度和阻带衰减，需根据实际指标权衡。
