## 一、实验目的
利用分析连续周期、连续非周期、离散周期、离散非周期信号的频谱，明确傅里叶变换与快速傅里叶变换之间关系，理解频谱分析的真实含义。具体通过连续周期方波信号的频谱分析，掌握采样率与截断长度对频谱混叠与泄漏的影响规律。

## 二、实验要求
利用MATLAB分析连续周期方波信号的频谱：
- 通过改变**采样率**研究频谱的**混叠**现象；
- 通过改变**时间截断长度**研究频谱的**泄漏**现象。

## 三、技术方案
1. **信号生成**：生成频率为 5 Hz 的周期方波信号（幅度归一化为 0~1），基波频率 `f0=5 Hz`，周期 `T=0.2 s`。
2. **截断长度对泄漏的影响**：
   - 采样频率 `fs1=100 Hz`（满足奈奎斯特条件）。
   - 取截断长度 `t1=0:Ts1:1-Ts1`，即 1 秒，包含 5 个完整周期（整数倍），预期无泄漏。
   - 取截断长度 `t2=0:Ts1:1.28-Ts1`，即 1.28 秒，包含 6.4 个周期（非整数倍），预期产生泄漏。
3. **采样率对混叠的影响**：
   - 降低采样频率至 `fs2=6 Hz`（低于方波最高谐波频率，不满足采样定理），截断长度取 10 秒以保证频率分辨率。
   - 观察频谱中高频分量折叠回低频区域，产生混叠现象。
4. **频谱计算**：对截断信号做 FFT，双边幅度谱归一化，并采用 `fftshift` 零频居中。

## 四、实验程序
完整 MATLAB 代码如下：

```matlab
clc;
clear;
close all;
 
% 高采样率（满足采样定理）
fs1 = 100; Ts1 = 1/fs1;
% 低采样率（不满足采样定理）
fs2 = 6;   Ts2 = 1/fs2;

% ---- 整周期截断（5个周期） ----
t1 = 0:Ts1:1-Ts1;
N1 = length(t1);
x1 = (square(2*pi*5*t1) + 1)/2;   % 方波 0~1
subplot(3,2,1); plot(t1,x1,'r'); title('5 个周期');
 
y1 = fft(x1, N1)/N1;
mag1 = abs(y1);
if mod(N1,2)==0
    k1 = -N1/2:(N1/2-1);
else
    k1 = -(N1-1)/2:(N1-1)/2;
end;
f1 = k1*fs1/N1;
subplot(3,2,2); stem(f1, fftshift(mag1), 'r'); xlim([-3,3]);
title('5周期频谱（无泄漏）');

% ---- 非整周期截断（6.4个周期） ----
t2 = 0:Ts1:1.28-Ts1;
N2 = length(t2);
x2 = (square(2*pi*5*t2) + 1)/2;
subplot(3,2,3); plot(t2,x2,'m'); title('6.4 个周期');
 
y2 = fft(x2, N2)/N2;
if mod(N2,2)==0
    k2 = -N2/2:(N2/2-1);
else
    k2 = -(N2-1)/2:(N2-1)/2;
end;
f2 = k2*fs1/N2;
mag2 = abs(y2);
subplot(3,2,4); stem(f2, fftshift(mag2), 'm'); xlim([-3,3]);
title('6.4周期频谱（泄漏）');

% ---- 低采样率（混叠） ----
t3 = 0:Ts2:10-Ts2;          % 长时间保证频率分辨率
N3 = length(t3);
x3 = (square(2*pi*5*t3) + 1)/2;
subplot(3,2,5); plot(t3,x3,'g'); title('采样率 6 Hz 信号');
 
y3 = fft(x3, N3)/N3;
if mod(N3,2)==0
    k3 = -N3/2:(N3/2-1);
else
    k3 = -(N3-1)/2:(N3-1)/2;
end;
f3 = k3*fs2/N3;
mag3 = abs(y3);
subplot(3,2,6); stem(f3, fftshift(mag3), 'g'); xlim([-3,3]);
title('低采样率频谱（混叠）');
```

## 五、实验结果
实验得到三组对比图（每个子图对应一个条件），分析如下：
<img width="704" height="376" alt="image" src="https://github.com/user-attachments/assets/9f15d68b-1a4e-40b1-b54f-fd9b7cbafaa0" />

1. **整周期截断（5个周期，`fs=100 Hz`）**：  
   - 幅度谱在基波 5 Hz 及其奇次谐波（15, 25 Hz 等）处出现清晰谱线，无多余频率分量，**无泄漏**。  
   - 符合理论预期，频率分量准确。

2. **非整周期截断（6.4个周期，`fs=100 Hz`）**：  
   - 频谱中原本单一的谱线发生展宽，能量扩散至相邻频点，出现许多非谐波位置的小谱峰，即**频谱泄漏**。  
   - 泄漏导致信号能量不再集中于谐波频率，幅值降低，产生假谱。

3. **低采样率（`fs=6 Hz`，截断 10 秒）**：  
   - 采样率远低于方波的有效带宽（方波谐波丰富，理论上无限带宽），不满足奈奎斯特条件。  
   - 高频谐波（如 15 Hz, 25 Hz 等）折叠回低频区域，与原有低频分量重叠，幅度谱形状严重失真，出现明显**频谱混叠**。  
   - 与第一组（高采样率）对比，混叠后无法分辨真实频率成分。

**结论**：  
- 截断长度必须为信号周期的整数倍，否则泄漏不可避免；  
- 采样频率必须满足奈奎斯特准则（至少 2 倍信号最高频率），否则高频成分会混叠至低频，造成不可恢复的失真。  
- 实际工程中需合理选择采样率和窗函数，兼顾频率分辨率和泄漏抑制。
