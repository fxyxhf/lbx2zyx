## 一、实验目的
利用分析连续周期、连续非周期、离散周期、离散非周期信号的频谱，明确傅里叶变换与快速傅里叶变换之间关系，理解频谱分析的真实含义。具体通过连续非周期信号的频谱分析，掌握采样率对频谱混叠的影响规律。

## 二、实验要求
利用MATLAB分析连续非周期信号的频谱：
- 通过改变采样率观察频谱混叠现象；
- 将该信号的离散频谱与理论频谱进行对比。

## 三、技术方案
选取两种典型连续非周期信号进行实验：
1. **指数衰减信号**：`x(t) = e^(-t)`（t≥0），其理论傅里叶变换为 `X(f) = 1 / (1 + j2πf)`，幅度谱为 `|X(f)| = 1 / sqrt(1 + (2πf)^2)`。
2. **矩形脉冲信号**：`x(t) = rect(t - 0.5)`（宽度为1，中心在0.5），其理论傅里叶变换为 `X(f) = sinc(f) * e^(-jπf)`，幅度谱为 `|X(f)| = |sinc(f)|`。

**方法**：
- 对同一模拟信号，分别采用高采样率（`fs=100 Hz`）和低采样率（`fs=5 Hz`）进行采样，通过FFT计算离散频谱。
- 将离散频谱与对应采样频率下的理论频谱曲线进行对比，观察低频采样时高频成分折叠回低频区域导致的混叠现象。
- 注意调整时域截断长度，以保证频率分辨率，尽量减少泄漏对混叠观察的干扰。

## 四、实验程序
完整 MATLAB 代码如下：

```matlab
clc;
clear;
close all;

% ===== 指数信号 =====
figure(1);
fs = 100; Ts = 1/fs;
t = 0:Ts:50-Ts;              % 长时间确保频率分辨率
x = exp(-t);
N = length(t);
y = fft(x) * Ts;             % 连续谱近似（乘以Ts）
z = abs(y);

if mod(N,2)==0
    k = -N/2:(N/2-1);
else
    k = -(N-1)/2:(N-1)/2;
end;
f = k*fs/N;

subplot(3,2,1), plot(t,x,'r'), title('指数信号, fs=100');
subplot(3,2,2), plot(f, fftshift(z), 'g'), xlim([-5,5]), title('幅度谱, fs=100');

% 低采样率
Ts1 = 0.2; fs1 = 1/Ts1;
t1 = 0:Ts1:5-Ts1;
x1 = exp(-t1);
N1 = length(t1);
y1 = fft(x1) * Ts1;
z1 = abs(y1);

if mod(N1,2)==0
    k1 = -N1/2:(N1/2-1);
else
    k1 = -(N1-1)/2:(N1-1)/2;
end;
f1 = k1*fs1/N1;
subplot(3,2,3), plot(t1,x1,'r'), title('指数信号, fs=5');
subplot(3,2,4), plot(f1, fftshift(z1), 'g'), ylim([0,1]), title('幅度谱, fs=5');

% 理论频谱（分别对应两个采样频率）
mag = abs(1./(1 + 1j*2*pi*f));
subplot(3,2,5), plot(f, mag, 'g'), xlim([-5,5]), title('理论幅度谱, fs=100');
mag1 = abs(1./(1 + 1j*2*pi*f1));
subplot(3,2,6), plot(f1, mag1, 'g'), title('理论幅度谱, fs=5');

% ===== 矩形脉冲信号 =====
figure(2);
t2 = 0:Ts:5-Ts;
x2 = rectpuls(t2-0.5, 1);     % 宽度1，中心在0.5
N2 = length(t2);
y2 = fft(x2) * Ts;
z2 = abs(y2);

if mod(N2,2)==0
    k2 = -N2/2:(N2/2-1);
else
    k2 = -(N2-1)/2:(N2-1)/2;
end;
f2 = k2*fs/N2;
subplot(3,2,1), plot(t2,x2,'r'), xlim([-2,5]), title('矩形脉冲, fs=100');
subplot(3,2,2), plot(f2, fftshift(z2), 'g'), xlim([-2.5,2.5]), title('幅度谱, fs=100');

% 低采样率
t3 = 0:Ts1:5-Ts1;
x3 = rectpuls(t3-0.5, 1);
N3 = length(t3);
y3 = fft(x3) * Ts1;
z3 = abs(y3);

if mod(N3,2)==0
    k3 = -N3/2:(N3/2-1);
else
    k3 = -(N3-1)/2:(N3-1)/2;
end;
f3 = k3*fs1/N3;
subplot(3,2,3), plot(t3,x3,'r'), xlim([-2,5]), title('矩形脉冲, fs=5');
subplot(3,2,4), plot(f3, fftshift(z3), 'g'), title('幅度谱, fs=5');

% 理论频谱
mag2 = abs(sinc(f2) .* exp(-pi*f2*1j));
subplot(3,2,5), plot(f2, mag2, 'g'), xlim([-2.5,2.5]), title('理论幅度谱 (fs=100)');

% 对比低采样率下的实际与理论
mag3 = abs(sinc(f3) .* exp(-pi*f3*1j));
subplot(3,2,6), plot(f3, mag3, 'r'), hold on;
plot(f3, fftshift(z3), 'g'), title('理论(红)与实际(绿), fs=5');
legend('理论', '实际');
```

## 五、实验结果

### 1. 指数信号
- **高采样率（`fs=100 Hz`）**：离散幅度谱与理论曲线高度吻合，在 `f=0` 处幅值最大，随频率升高单调递减，无混叠。
- **低采样率（`fs=5 Hz`）**：离散频谱在低频段（`-2.5~2.5 Hz`）出现明显失真，高频端的拖尾能量被折叠回低频，导致实际谱线高于理论值，出现**频谱混叠**。
- 对比可知，采样率越低，混叠越严重。

### 2. 矩形脉冲信号
- **高采样率（`fs=100 Hz`）**：离散频谱很好地逼近理论 `sinc` 形状，主瓣和旁瓣清晰可辨。
- **低采样率（`fs=5 Hz`）**：由于矩形脉冲带宽无限，即使 `fs=5` 也远不满足采样定理，频谱中高频旁瓣的能量大量折叠至低频区域，实际谱与理论谱差异显著（第六子图中红绿曲线明显分离），混叠严重。

### 3. 综合分析
- 对于非周期信号，其频谱通常是连续且无限带宽的，因此无论采样率为多少，严格来说都会产生混叠（除非信号带限且采样率足够高）。
- 当采样率降低时，混叠造成的频谱失真愈发明显，离散频谱无法正确反映真实频率成分。
- 实验中还应注意时域截断长度，长度过短会引入泄漏，干扰对混叠的观察；本实验采用较长时域数据，故泄漏影响可忽略。

**结论**：
- 采样率必须根据信号的最高有效频率来选择，对于非带限信号，应通过抗混叠滤波器或提高采样率来减少混叠误差。
- FFT分析的离散频谱只能近似连续谱，采样率和截断长度是影响近似精度的两个关键因素。
