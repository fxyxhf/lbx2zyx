## 一、实验目的
利用分析连续周期、连续非周期、离散周期、离散非周期信号的频谱，明确傅里叶变换与快速傅里叶变换之间关系，理解频谱分析的真实含义。具体通过连续正弦信号的频谱分析，掌握时间截断长度和窗函数对频谱泄漏的影响规律。

## 二、实验要求
利用MATLAB分析连续正弦信号的频谱：
- 改变时间截断长度，研究其对频谱泄漏的影响；
- 采用不同窗函数（三角窗、矩形窗）对信号进行时域截断，研究对频谱泄漏的影响。

## 三、技术方案
1. **信号生成**：生成频率为 25 Hz 的连续正弦信号，采样频率 `fs=1000 Hz`，采样间隔 `Ts=1/fs`。
2. **截断长度设置**：
   - 信号周期 `T=1/25=0.04 s`。
   - 设置第一个截断长度 `t=0:Ts:(0.12-Ts)`，长度为 `0.12 s`，是周期的整数倍（3倍），理论上无频谱泄漏。
   - 设置第二个截断长度 `t=0:Ts:(0.14-Ts)`，长度为 `0.14 s`，非周期整数倍，预期产生频谱泄漏。
3. **频谱计算**：对截断后的信号进行 FFT，并做幅度谱（归一化），采用频移 `fftshift` 使零频居中。
4. **窗函数对比**：分别对非整周期截断信号施加三角窗（`bartlett`）和矩形窗（`rectwin`），比较加窗前后的幅度谱变化，分析窗函数对频谱泄漏的抑制作用。

## 四、实验程序
完整 MATLAB 代码如下（以非整周期截断为例，程序中将截断长度注释掉以便切换）：

```matlab
clc;
clear;
close all;
 
fs = 1000;
Ts = 1/fs;
% t = 0:Ts:(0.12-Ts);      % 整周期截断（3个周期）
t = 0:Ts:(0.14-Ts);        % 非整周期截断
x = sin(2*pi*25*t);
N = length(t);
y = fft(x)/N;
z1 = abs(y);
 
% 频率轴（双边）
if mod(N,2)==0
    k = -N/2:(N/2-1);
else
    k = -(N-1)/2:(N-1)/2;
end;
f = k*fs/N;
 
% 绘制原始信号及幅度谱
subplot(4,1,1), plot(t,x,'r'), title('正弦信号');
subplot(4,1,2), stem(f, fftshift(z1), 'g'), title('幅度谱（未加窗）');
 
% 加三角窗
w = bartlett(N);
x1 = x .* w';
y1 = fft(x1)/N;
z3 = abs(y1);
subplot(4,1,3), stem(f, fftshift(z3)), title('加三角窗后幅度谱');
 
% 加矩形窗
w1 = rectwin(N);
x2 = x .* w1';
y2 = fft(x2)/N;
z4 = abs(y2);
subplot(4,1,4), stem(f, fftshift(z4), 'c'), title('加矩形窗后幅度谱');
```

> **说明**：程序中通过切换 `t` 的定义可分别测试整周期和非整周期截断情况。

## 五、实验结果
<img width="686" height="358" alt="image" src="https://github.com/user-attachments/assets/b2981686-bf14-4545-b62d-a081c96b82f8" />
1. **整周期截断（`t=0:Ts:(0.12-Ts)`）**：幅度谱在 ±25 Hz 处呈现单一谱线，其余频率点幅值为零（或极小数值误差），无频谱泄漏现象，符合理论预期。
2. **非整周期截断（`t=0:Ts:(0.14-Ts)`）**：幅度谱中能量从 25 Hz 泄露至相邻频点，出现多根幅度衰减的谱线，频谱泄漏明显，如下图所示（第二子图）。
3. **加矩形窗**：矩形窗相当于对信号直接截断，其频谱与未加窗完全一致，故不能抑制泄漏。
4. **加三角窗**：旁瓣衰减较大，但主瓣宽度增加，导致频率分辨力下降，泄漏虽有所抑制但主瓣变宽，旁瓣水平降低，但整体防泄漏效果不如其他高性能窗函数（如汉宁窗）。

**结论**：  
- 时间截断长度为信号周期的整数倍时，频谱无泄漏；否则泄漏不可避免。  
- 窗函数可改善频谱泄漏，但不同窗函数在旁瓣衰减与主瓣宽度之间存在折中，需根据实际需求选择。
