## 一、实验目的
利用分析连续周期、连续非周期、离散周期、离散非周期信号的频谱，明确傅里叶变换与快速傅里叶变换之间关系，理解频谱分析的真实含义。通过离散非周期信号的频谱分析，掌握栅栏效应和补零对频谱结果的影响规律。

## 二、实验要求
利用MATLAB分析离散非周期信号的频谱：
- 分别用数据长度 \(N=20\) 和 \(N=500\) 观察信号的频谱分析（即做 \(N\) 点 FFT）结果，分析**栅栏效应**；
- 然后将 \(N=20\) 的数据后面补 \(480\) 个零，做 \(500\) 点 FFT，明确**高密度频谱**与**高分辨率频谱**的关系。

## 三、技术方案
1. **信号生成**：构造离散非周期信号  
   \[
   x[n] = \cos(0.84\,n) + \cos(0.96\,n),\quad n=0,1,\cdots,N-1
   \]
   其中两个数字频率分别为 \(0.84\) rad/sample 和 \(0.96\) rad/sample，频率间隔为 \(0.12\) rad/sample。

2. **栅栏效应分析**：
   - 对 \(x[n]\) 分别做 \(N=20\) 点和 \(N=500\) 点的 FFT，得到离散频谱 \(X[k]\)。
   - FFT 只在归一化频率 \(f_k = k/N\)（\(k=0,1,\cdots,N-1\)）处采样。当信号频率不是 \(1/N\) 的整数倍时，谱线会偏离真实峰值，导致观察到的幅度谱失真，此即“栅栏效应”。
   - 增加数据长度（\(N=500\)）能提高频率分辨率（\(\Delta f = 1/N\)），使谱线更密集，从而更准确地逼近连续频谱，抑制栅栏效应。

3. **补零实验**：
   - 取 \(N=20\) 的原始数据，在其后补 \(480\) 个零，形成长度为 \(500\) 的序列，再做 \(500\) 点 FFT。
   - 补零增加了频域采样点数，使频谱曲线更光滑，但并未改变实际频率分辨率（仍由原始有效数据长度 \(20\) 决定），因此得到的是“高密度频谱”而非“高分辨率频谱”。

4. **对比**：比较三种情况下的幅度谱，明确高分辨率（长数据）与高密度（补零）的区别。

## 四、实验程序
完整 MATLAB 代码如下：

```matlab
clc;
clear;
close all;

% ---- N=20 点 FFT ----
N = 20;
n = 0:N-1;
x = cos(0.84*n) + cos(0.96*n);
y = fft(x);
if mod(N,2)==0
    k = -N/2:(N/2-1);
else
    k = -(N-1)/2:(N-1)/2;
end;
f = k/N;                % 归一化频率
mag = abs(y);
subplot(3,1,1), plot(f, fftshift(mag), 'k');
title('N=20 点 FFT (栅栏效应明显)');

% ---- N=500 点 FFT (高分辨率) ----
N1 = 500;
n1 = 0:N1-1;
x1 = cos(0.84*n1) + cos(0.96*n1);
y1 = fft(x1);
if mod(N1,2)==0
    k1 = -N1/2:(N1/2-1);
else
    k1 = -(N1-1)/2:(N1-1)/2;
end;
f1 = k1/N1;
mag1 = abs(y1);
subplot(3,1,2), plot(f1, fftshift(mag1), 'k');
title('N=500 点 FFT (高分辨率)');

% ---- N=20 补零到 500 点 (高密度) ----
N2 = 20;
N22 = 500;
n2 = 0:N2-1;
x2 = cos(0.84*n2) + cos(0.96*n2);
y2 = fft(x2, N22);      % 自动补零到 500 点
if mod(N22,2)==0
    k2 = -N22/2:(N22/2-1);
else
    k2 = -(N22-1)/2:(N22-1)/2;
end;
f2 = k2/N22;
mag2 = abs(y2);
subplot(3,1,3), plot(f2, fftshift(mag2), 'k');
title('N=20 补 480 个零后做 500 点 FFT (高密度)');
```

## 五、实验结果
实验结果如下图所示（三幅子图分别对应上述三种情况）：
<img width="700" height="383" alt="image" src="https://github.com/user-attachments/assets/93face19-ad65-473c-92a5-567392ddd518" />

1. **\(N=20\) 点 FFT**：频谱仅在 20 个离散频率点上采样，由于两个信号频率 \(0.84\) 和 \(0.96\) 并非 \(1/20=0.05\) 的整数倍，谱峰未能精确落在真实频率位置，出现明显的**栅栏效应**，导致无法清晰分辨两个频率成分，幅度谱形状粗糙。

2. **\(N=500\) 点 FFT**：数据长度大幅增加，频率分辨率提升至 \(1/500=0.002\)，谱线足够密集，两个频率成分在频谱中清晰地分离为两个独立的峰，且峰值位置与真实频率基本吻合，栅栏效应得到有效抑制，此为**高分辨率频谱**。

3. **\(N=20\) 补零至 500 点**：频谱曲线变得光滑、细密，但由于有效数据长度仍为 20，频率分辨率并未提高，两个频率成分依然无法分辨（合并为一个宽峰），只是看起来更加“精细”。此即为**高密度频谱**——通过补零增加了频域采样点数，但没有增加实际的信息量，不能提高分辨能力。

**结论**：
- 栅栏效应源于 FFT 在离散频率点上的有限采样，增加数据长度（而非补零）是提高频率分辨率的根本方法。
- 补零可以改善频谱的可视化效果，使谱线更平滑，但无法区分靠得很近的频率成分，仅提供高密度采样，不提升分辨率。
